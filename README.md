# 어른이 되면 (가제)

새벽 2시, 자소서를 쓰다 멈춘 방에 열 살의 내가 보낸 편지가 날아온다. "꿈꾸던 어른이 되었나요?"

5분 안에 끝나는 3D 웹 스토리. 열 살의 나에게 어른 방을 구경시켜 주고, 열 살의 나에게 답장을 쓰고, "나는 ○○형 어른" 카드를 공유한다.

- 대본: [app/data/script.ts](app/data/script.ts) (확정 v1, 2026.11.22). 대사는 이 파일만 고친다.
- 기획 세션 기록 (무엇을 왜 정했는지): [docs/planning-session.md](docs/planning-session.md)
- 이야기의 중심: 열 살의 꿈은 직업 이름이었지만 그 안에는 "마음"이 있었다. 직업은 못 됐어도 그 마음은 아직 있다.

## 실행

```
npm install
npm run dev        # http://localhost:3000
npm run typecheck
npm run build
```

## 장면 (약 5분)

| # | 장면 | 하는 것 | 시간 |
| --- | --- | --- | --- |
| 0 | 새벽 2시의 방 | 탈락 알림을 보고 노트북 덮기 | 20초 |
| 1 | 날아온 편지 | 번진 편지 칸에 어릴 적 꿈 고르기 (6개) | 1분 |
| 2 | 어른 방 구경 | 아이가 내 방 물건(커피, 정장, 이력서 등)을 하나씩 묻고 내가 대답을 고름. 보여 줄수록 방이 밝아짐 | 1분 |
| 3 | 열 살의 질문 | 질문 3개. 두 번째 질문 뒤에 꿈속에 있던 마음이 밝혀짐 | 1분 30초 |
| 4 | 답장 | 문장 하나 고르고 별로 접어 하늘로 보내기 | 1분 |
| 5 | 결과 | 꿈에 따라 유형 6개 중 하나. 공유 카드 | 30초 |

선택은 결과 유형과 대사 몇 줄만 바꾼다. 장면이 갈라지지 않는다.

| 이벤트 | 값 |
| --- | --- |
| `story_start` | `ref` |

| `result_viewed` | `type` |
| `share_clicked` | `channel` |

핵심 숫자: 완주율, 공유율, 공유 1회당 새 방문자, 장면별 이탈률. 편지 내용 같은 개인적인 글은 분석 도구로 보내지 않는다.

## 기술

- 지금 있음: Nuxt 4, TresJS 5 (three.js를 Vue 컴포넌트로), TypeScript
- 필요할 때 붙임: GSAP (카메라 이동), Pinia (진행 상황 저장), Tailwind CSS, PostHog, Supabase (2단계 공유 밤하늘), 카카오 공유 SDK
- 배포: Netlify
- 3D 모델은 만들지 않는다. 방은 상자 몇 개로 만들고 AI 이미지를 평면에 붙여 디오라마처럼 보이게 한다 (2.5D). 밤하늘 별은 InstancedMesh.

## 이미지 프롬프트

그림 17장의 전체 프롬프트, 파일 이름, 크기: [docs/image-prompts.md](docs/image-prompts.md)

모든 프롬프트 앞에 같은 스타일 문장을 붙여 톤을 맞춘다.

```
soft gouache illustration, warm desk lamp glow, deep navy night,
amber highlights, gentle film grain, cozy and quiet mood, no text, no letters
```

- 그림에는 글자를 넣지 않는다. 글자는 HTML로 얹는다.
- 특정 작가나 스튜디오 이름은 넣지 않는다.
- 필요한 그림 17장: 창밖 밤 도시, 편지지, 크레용 그림 8장(공통 2장, 꿈마다 1장), 결과 카드 6장, 공유 미리보기 1장. 열 살의 나 캐릭터는 따로 그리지 않는다 (여러 장에서 같은 얼굴을 맞추기 어려움).
- 비율: 결과 카드 9:16, 공유 미리보기 1.91:1

## 단계

| 단계 | 만들 것 | 끝났다는 기준 |
| --- | --- | --- |
| 0. 준비 | 대본 확정 (끝), 스타일 시안 3~4장 | 대본 파일, 시안 이미지 |
| 1. MVP | 5장면, 결과 카드 6종, PostHog, Netlify 배포 | 카카오톡 인앱 브라우저에서 끝까지 플레이됨 |
| 2. 퍼지게 | 카카오 공유, 공유 밤하늘, 배지 | 공유 링크 유입이 `ref`로 집계됨 |
| 3. 다시 오게 | 오늘의 편지, 친구 링크 편지, 첫 문구 A/B 테스트 | 재방문율이 보임 |

## 조심할 것

- 인앱 브라우저(카카오톡, 인스타) 성능: 저사양 모드(별 개수 줄이기, 해상도 배율 1)를 MVP부터 넣는다.
- 공유 밤하늘에는 미리 만든 문장만 보인다. 자유 입력은 본인만 본다.
- 결과 화면에 자살예방 상담전화 109 안내를 넣는다.
- 카카오 공유는 카카오 개발자 사이트에 앱과 도메인 등록이 필요하다.

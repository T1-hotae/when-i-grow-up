## 1. 처음 요청

> Vue + Nuxt + Three.js 를 활용한 프로젝트를 만들어야할 것 같아.
> 배포도 할 수 있을만한 게이미피케이션있는 요소와
> 사용자 분석할 수 있는 도구도 추가하고,
> 약간 취업이 안되는 사람들, 그리고 꿈꾸던 어른이 되었나요? 처럼 위로를 줄만한 그런
> 스트레스 해소용 웹사이트 스토리도 있고,
> 이미지는 프롬프트로 뽑아서 할거고
> 느낌있게, 다른 이런 웹 기반 게임 분석해서 시나리오 계획해주고
> 잠깐 즐길 수 있을 용도로 해줘.
> 다른 바이럴 된 사이트도 참고해서

## 2. 한 줄 소개

새벽 2시, 자소서를 쓰다 멈춘 방에 열 살의 내가 보낸 편지가 날아온다. "꿈꾸던 어른이 되었나요?"

5분 안에 끝나는 3D 웹 스토리. 걱정을 구겨서 던지고, 열 살의 나에게 답장을 쓰고, "나는 ○○형 어른" 카드를 공유하며 끝난다.

## 3. 레퍼런스 분석

| 레퍼런스 | 왜 퍼졌나 | 가져올 것 |
| --- | --- | --- |
| 내 트리를 꾸며줘 (2021) | 내 트리 링크를 인스타 스토리에 올리면 친구들이 와서 메시지를 남기고, 메시지는 크리스마스에 열린다. 출시 4일 만에 이용자 182만 명, 메시지 2,190만 개. | "내 링크"로 친구를 부르는 구조, 정해진 날에 열리는 기다림 |
| 테토/에겐 테스트 (2025) | "나는 ○○형"이라는 유형이 자기소개가 된다. 2025년 4월 말 MBTI 테스트를 근소하게 앞섰다는 보도가 있다. | 결과 유형과 공유 카드 |
| 나의 가치 여정 | 긍정 단어를 고르고 덜어내 핵심 가치 5개를 남긴다. 고르는 과정 자체가 기분 좋다. | 좋은 말을 고르게 하는 방식 |
| Kind Words (2019) | 아늑한 방, 로파이 음악, 낯선 사람과 익명 위로 편지를 주고받는다. 오간 편지가 530만 통이 넘는다. 트롤링 사례도 있었다. | 방 분위기, 위로 주고받기. 자유 글 공개는 뺀다 (검열 부담) |
| Slow Roads | three.js 브라우저 드라이빙. 목표 없이 편하게 달린다. "브라우저에서 이게 돼?" 하는 놀라움이 공유로 이어졌다. 충돌이나 부서짐 같은 기능을 빼서 가볍다. | 목표 없는 편안함, 기능을 줄여서 얻는 성능 |
| neal.fun, Wordle | 아이디어 하나, 1분이면 이해, 로그인 없음. Wordle은 하루 한 번 하고 결과를 공유한다. (검색으로 확인하지 않고 아는 내용으로 씀) | 첫 화면 버튼 하나, 하루 한 번 할 거리 |

검색 결과에는 2025~2026년 바이럴 순위 같은 공식 자료가 없어서, 확인된 사례 위주로 골랐다.

**공통 원칙 6개**
1. 3초 안에 뭘 하는 건지 안다
2. 로그인이 없다
3. 5분 안에 끝난다
4. 결과가 "나"에 대한 말이라 공유하고 싶다
5. 공유 링크가 다음 사람의 시작점이 된다
6. 다시 올 이유가 있다

## 4. 시나리오

**이야기의 중심**: 열 살 때 꿈은 직업 이름이었지만, 그 안에는 "마음"이 있었다. 그 직업은 못 됐어도 마음은 아직 있다. 장면 3에서 이걸 뒤집어 보여 준다.

| # | 장면 | 하는 것 | 시간 |
| --- | --- | --- | --- |
| 0 | 새벽 2시의 방 | 탈락 알림 두 개와 엄마 메시지를 보고 노트북 덮기 | 20초 |
| 1 | 날아온 편지 | 물에 번진 편지 칸에 어릴 적 꿈 고르기 (6개) | 1분 |
| 2 | 걱정 구기기 | 걱정 종이를 구겨 휴지통에 던지기. 던질수록 방이 밝아짐 | 1분 |
| 3 | 열 살의 질문 | 질문 3개. 두 번째 질문 뒤에 "내가 ○○ 되고 싶었던 건, ~해서였어"로 마음이 밝혀짐 | 1분 30초 |
| 4 | 답장 | 문장 하나 고르고 별로 접어 하늘로 보내기 | 1분 |
| 5 | 결과 | 꿈에 따라 유형 6개 중 하나. 공유 카드와 상담전화 109 안내 | 30초 |

**대본 원칙**
- 한 화면에 두 줄까지 (휴대폰 기준)
- 아이는 어떤 답에도 실망하지 않는다
- 웃긴 말 하나, 진지한 말 하나를 번갈아
- "힘내", "넌 할 수 있어"는 쓰지 않는다
- 실제 회사 이름은 쓰지 않는다
- 아이는 화면에 나오지 않고, 편지지에 글씨가 저절로 써지는 방식으로 말한다

**꿈과 결과 유형**

| 꿈 | 마음 | 유형 |
| --- | --- | --- |
| 우주비행사 | 아무도 안 가 본 데 가 보고 싶어서 | 종이비행기형 어른 |
| 선생님 | 누가 나 때문에 뭘 알게 되면 기분 좋아서 | 등대형 어른 |
| 의사 | 아픈 사람이 안 아팠으면 해서 | 우산형 어른 |
| 연예인 | 사람들이 나 보고 웃으면 좋아서 | 모닥불형 어른 |
| 화가 | 내가 본 예쁜 걸 다른 사람한테도 보여 주고 싶어서 | 늦게 피는 꽃형 어른 |
| 기억이 안 나 (치킨집 사장) | 그냥 재밌게 살고 싶어서 | 고양이형 어른 |

전체 대사는 `app/data/script.ts`에 있다.

## 5. 게이미피케이션

| 요소 | 방식 | 이유 | 단계 |
| --- | --- | --- | --- |
| 결과 유형 6종 | 고른 꿈으로 유형 결정, 다른 유형 구경하기 | "나는 ○○형"이라고 공유하고 싶게 | MVP |
| 걱정 던진 개수 | 결과 카드에 "오늘 버린 걱정 N개" | 던지는 손맛, 공유할 숫자 | MVP |
| 공유 밤하늘 | 지금까지 띄운 별 개수와 내 별 위치 | 나만 힘든 게 아니라는 느낌 | 2단계 |
| 배지 | 새벽 방문, 3일 연속 방문, 유형 다 모으기 | 다시 오게 | 2단계 |
| 오늘의 편지 | 하루 한 통 짧은 편지 (Wordle 방식) | 재방문 | 3단계 |
| 친구 링크 편지 | 내 링크를 받은 친구가 열 살의 나 대신 편지를 쓰고, 정한 날에 열림 | 내 트리를 꾸며줘 방식의 확산 | 3단계 |
| 순위표 | 넣지 않음 | 경쟁은 위로 컨셉과 안 맞음 | - |

## 6. 사용자 분석

PostHog 하나로 시작한다. 이벤트, 퍼널(어느 단계에서 나가는지), 재방문, 세션 녹화, A/B 테스트가 한 도구로 된다. GA4는 붙이지 않는다.

| 이벤트 | 값 | 알 수 있는 것 |
| --- | --- | --- |
| `story_start` | `ref` | 누가 공유한 링크로 왔는지 |
| `chapter_complete` | `chapter` | 어느 장면에서 그만두는지 |
| `choice_made` | `chapter`, `option` | 많이 고르는 답 |
| `worry_thrown` | `count` | 걱정 던지기 장면이 먹히는지 |
| `result_viewed` | `type` | 유형 분포 |
| `share_clicked` | `channel` | 공유율 (카카오, 인스타, 링크) |
| `perf_sample` | `fps`, `device` | 모바일 성능 |

핵심 숫자: 완주율, 공유율, 공유 1회당 새 방문자, 장면별 이탈률. 편지 내용 같은 개인적인 글은 분석 도구로 보내지 않는다.

## 7. 기술

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 프레임워크 | Nuxt 4 + TypeScript | 결과 페이지마다 공유 미리보기를 서버에서 만들 수 있음 |
| 3D | TresJS 위에 three.js | three.js를 Vue 컴포넌트처럼 씀. 밤하늘 별은 InstancedMesh |
| 애니메이션 | GSAP | 카메라 이동, 장면 전환 |
| 상태 | Pinia | 진행 상황 저장 |
| 스타일 | Tailwind CSS | 이미 쓰던 것 |
| 서버 (2단계) | Nuxt 서버 API + Supabase | 공유 밤하늘, 친구 편지 |
| 공유 | 카카오 공유 SDK, Web Share API | 한국에서는 카카오톡 공유가 필수 |
| 배포 | Netlify | 포트폴리오도 Netlify |

3D 모델은 만들지 않는다. 방은 상자 몇 개로 만들고, AI 이미지를 평면에 붙여 디오라마처럼 보이게 한다 (2.5D).

## 8. 단계

| 단계 | 만들 것 | 끝났다는 기준 |
| --- | --- | --- |
| 0. 준비 | 대본 확정, 그림 뽑기 | 대본 파일, 그림 17장 |

| 2. 퍼지게 | 카카오 공유, 공유 밤하늘, 배지 | 공유 링크 유입이 `ref`로 집계됨 |
| 3. 다시 오게 | 오늘의 편지, 친구 링크 편지, 첫 문구 A/B 테스트 | 재방문율이 보임 |

## 9. 조심할 것

- 바이럴 유입은 대부분 카카오톡이나 인스타 안의 브라우저로 들어온다. 저사양 모드(별 개수 줄이기, 해상도 배율 1)를 MVP부터 넣는다.
- 공유 밤하늘에는 미리 만든 문장만 보인다. 자유 입력은 본인만 본다.
- 힘든 사용자를 위해 결과 화면에 자살예방 상담전화 109 안내를 넣는다.
- 카카오 공유는 카카오 개발자 사이트에 앱과 도메인 등록이 필요하다.

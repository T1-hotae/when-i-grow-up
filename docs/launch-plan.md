# 출시·홍보 계획

## 배경
6분짜리 3D 웹 스토리(Nuxt 4 + TresJS). 배포 주소는 https://when-i-grow-up-rust.vercel.app/ 이고, 공유가 퍼지는 구조(결과 카드 → /result/:id 링크)는 이미 있음. 목표: 20~30대 취준생/직장인에게 "결과 카드 공유"로 퍼지게 하기.

## 1. 출시 전에 코드에서 손볼 것
- [x] **배포처: Vercel** — https://when-i-grow-up-rust.vercel.app/
- [x] **편지 저장소**: 배포에선 Upstash Redis에 쌓도록 `nuxt.config.ts` `$production.nitro.storage.data`에 지정(개발 땐 그대로 `.data/kv` 파일).
  - [ ] **남은 일**: [upstash.com](https://upstash.com)에서 Redis DB를 만들고, Vercel 프로젝트 Settings → Environment Variables에 `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` 두 개를 넣은 뒤 다시 배포. Vercel Marketplace로 연결하면 이름이 `KV_REST_API_URL`/`KV_REST_API_TOKEN`으로 생기니, 같은 값으로 위 두 이름을 하나씩 더 만들어 줍니다. 안 넣으면 편지만 저장 안 되고 이야기는 그대로 진행됩니다.
- [x] **첫 화면 공유 미리보기**: `nuxt.config.ts` head에 og 태그와 twitter:card 추가(사이트 주소는 맨 위 `SITE`). 결과 페이지는 `result/[id].vue`가 덮어씀.
- [x] **방문 집계**: Vercel Analytics 스크립트(`/_vercel/insights/script.js`)를 배포 빌드에만 넣음. `@vercel/analytics` 패키지는 vue-router 5와 안 맞아 안 씀.
  - [ ] **남은 일**: Vercel 프로젝트 → Analytics 탭에서 Enable. 페이지뷰만 셈(결과 유형별 이벤트는 유료 플랜 기능이라 뺌. 유형 분포는 편지 저장소로 봄).
- [x] **무게 점검**: public 25MB 중 17MB가 배경음악(곡당 3~4MB)인데, 장면마다 그 곡만 스트리밍으로 받아서 첫 진입엔 안 받음. 그림도 장면에서만 불러옴. 지금은 손볼 것 없음. 실제 폰 LTE로 한 번 체감 확인만.
- **도메인(선택)**: `.vercel.app`로 시작, 반응 오면 1~2만원대 도메인.

## 2. 출시 전 1주: 소수 테스트
- 친구 5~10명에게 링크 → "어디서 멈췄는지, 어디서 울컥했는지" 2개만 물어보기.
- 아이폰 사파리 / 갤럭시 삼성인터넷 / 카톡 인앱 브라우저 3개는 꼭 확인 (3D·소리 자동재생이 제일 잘 깨짐).

## 3. 홍보 자료 (한 번 만들어서 돌려쓰기)
- **15~30초 세로 영상**: 탈락 메일 → 눈 감기 → 열 살의 나 "나 커서 뭐가 됐어?" → 결과 카드. 이게 핵심 자산 (릴스·쇼츠·틱톡 동일 업로드).
- **결과 카드 12종 이미지**: "나는 ○○형 어른" 모음 캐러셀 — 인스타 게시물용.
- **한 줄 소개**: "어젯밤 꿈에 열 살의 내가 나왔어요. 나 커서 뭐가 됐어?" (이미 있음 그대로).

## 4. 채널 (우선순위 순)
1. **인스타/틱톡/쇼츠** — 테스트형 콘텐츠가 가장 잘 퍼지는 곳. 영상 + "결과 댓글로 알려줘" 유도.
2. **커뮤니티**: 에브리타임(학교), 블라인드·잇플(직장인), 더쿠·인스티즈 "심테/테스트" 게시판, 디시 취업갤. 광고 티 없이 "만들어 봤는데 해봐 줘"로.
3. **X(트위터)**: 감성 짧은 글 + 결과 카드. 리트윗형 확산.
4. **개발자 쪽**: GeekNews(Show GN), 디스코드/오픈카톡 개발 커뮤니티, velog 제작기("Nuxt+Three.js로 6분짜리 웹 스토리 만든 이야기"). 포트폴리오 겸용.
5. **학교**: 학교 커뮤니티·학과 단톡, 교내 공모전/캡스톤 전시 출품.
6. (반응 오면) 테스트 모음 사이트/뉴스레터에 제보: 케이테스트 류, 뉴닉·캐릿 같은 MZ 뉴스레터 제보 메일.

## 5. 타이밍
- **수능 끝난 직후 ~ 연말(지금, 11월 말~12월)** "올해 나 뭐 했지" 회고 시즌이 딱 맞음 → 12월 첫째 주 출시 추천.
- 출시일: 영상 + 커뮤니티 2~3곳 동시에. 이후 3일 간격으로 채널 하나씩 추가.
- 하반기 공채 결과 발표 시기와도 맞물림 (탈락 메일 장면 공감대).

## 6. 출시 후
- 1주차: Analytics에서 이탈 지점 보고 그 장면만 다듬기.
- 진로 통계: "꿈 이뤘어?"에 "다른 길로 왔어"를 고른 사람은 지금 가는 길(`path`: 분야 6개, 직접 쓴 글, 비밀이면 null)이 편지와 같이 쌓임 → "어릴 때 ○○형 → 지금 □□" 묶어 보기. Upstash 콘솔에서 내려받아 엑셀로.
- 결과 유형 분포(편지 저장소)로 "취준생 OO%는 과학자형" 같은 2차 콘텐츠 만들기 → 재홍보.
- 커피 후원 링크는 이미 있음(script.ts `scene5.coffee`), 그대로.
